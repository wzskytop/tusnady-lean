- Default builds now include `R56Audit`; verification and packaging cover every supplement source and audit file.
- The supplement audit is integrated into the full verifier, together with independent unfolded statements and an unrestricted dependency traversal.
- macOS whitespace in the shell module count is normalized before summary comparison.

- Stable supplement expectations are retained; legacy archive diagnostics remain checked and logged separately from the supplement summary. Supplement numerical expectations are not regenerated during CI.

- The original Claude audit report is included as a historical input report, with a notice distinguishing its original archive claims from this integrated repository.

## Reproducibility

Run `python3 scripts/verify.py --replay`. This builds all 91 local modules, strictly recompiles the 33 supplement modules, audits all 907 supplement constants, checks 353 statement/definition examples, rejects 52 mutations with three accepted controls, checks five independent semantic interfaces, verifies both primary proof closures, and replays all 89 non-umbrella modules. The legacy library's axiom, route, and eight statement checks remain active.

Only the standard axioms `propext`, `Classical.choice`, and `Quot.sound` are accepted. The compiled-environment audit additionally checks extensions, names, attributes, and all supplement constants. The legacy compiler-generated unsafe auxiliary for `Riesz.Moments.SampleSpace` is recorded by the archive audit; no accepted proof depends on it.

The verifier records manuscript/source hashes, dependency revisions, platform, Git commit, GitHub run identifier, and complete logs. A current success receipt is written only after all requested checks pass. Packaging requires full replay and verifies the exact bytes of the source and evidence. These records establish reproducibility and consistency, not an external mathematical or authorship attestation.
